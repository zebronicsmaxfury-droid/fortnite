2) TRAINING MODE CHANGES  (js/game/training.js, plus 2 hooks)

2a) ALL vehicles spawn in a vertical line
Root cause: Training mode never calls FN.Vehicles.init(), so no drivable vehicles are registered.
Add TR.buildVehicles() and call it from TR.start() right after TR.buildDummies():
- FN.Vehicles.init();
- For i-th entry v of FN.Vehicles.list, set v.prop:
    x = SPAWN_X + 24            (constant -> vertical line)
    z = (SPAWN_Z - 16) + i * 8  (8 m spacing fits the 7.4 m truck)
    rot = Math.PI / 2           (nose-to-tail along the line)
    y = FN.Terrain.heightAt(x, z) + v.def.groundOffset
  then FN.Props.writeInstance(v.prop).
- BEFORE repositioning, save {prop, x, z, rot, y} into TR.vehicleLine; in TR.stop() restore
  all saved values and writeInstance each prop (so leaving training restores the world).

2b) ADD 3 static, KILLABLE target dummies near the vehicles; respawn 1 s after death
Add TR.buildTargets() and call it from TR.start() after TR.buildDummies():
- 3 dummies at x = (SPAWN_X + 24) - 7, z = (SPAWN_Z - 16) + i * 12, group.rotation.y = Math.PI/2.
- Each entry: { x0, z0 (spawn point), x, y, z, char (FN.Character.create(...), added to FN.Engine.scene),
  health:100, hurt:0, dead:false, respawnT:0, isBot:false, isDummy:true, killable:true, team:99,
  inv:FN.Inventory.create(), equip:{slot:0,item:null}, stats:{kills:0} }.
Damage: TR.applyDummyDamage currently only flashes "hurt". Extend it:
- Early-return if dummy.dead. After showing damage numbers: if dummy.killable -> dummy.health -= amount;
  when health <= 0: set dead=true, health=0, call FN.Character.beginDeath(dummy.char), play FN.Audio.play('death', pos, 0.7).
Update loop: in TR.update() add a block for TR.targets:
- If dead and char.deathFx -> drive FN.Character.updateDeath(d.char, dt); when it returns true:
  FN.Character.endDeath, hide group, d.respawnT = 1.0.
- If dead and no deathFx -> count down respawnT; at <= 0: respawn AT THE SAVED SPOT (x0/z0),
  reset health/hurt/dead, set group position/rotation, group.visible = true.
- While alive: static stance only (FN.Character.animate with move:0, no position changes).
Raycasts: in js/game/combat.js there are THREE places that push training dummies into the

Respawn timing note: "1 second" is measured after the death FX fully finishes (~2.9 s after the
killing blow + 1 s pause). This is required because the shared death animation owns the body.
